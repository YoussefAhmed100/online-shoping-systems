## Overview

**online-shoping-systems** is a powerful developer tool designed to streamline the creation of scalable e-commerce applications.

### Why online-shoping-systems?

This project simplifies server-side development while ensuring robust architecture and security. The core features include:

- 🔌 **Modular Architecture**: Enhances maintainability and scalability, allowing developers to build applications efficiently.
- 🔒 **Built-in Authentication**: Simplifies user management with JWT and role-based access control, enhancing security.
- ☁️ **Cloudinary Integration**: Streamlines media management for images and videos, improving user experience.
- 📃 **Comprehensive API Documentation**: Automatically generated with Swagger, making it easier for developers to understand and use the API.
- ✅ **End-to-End Testing**: Ensures application reliability by validating core functionalities through automated tests.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: TypeScript
- **Package Manager**: Npm

---

### Installation

Build online-shoping-systems from the source and install dependencies:

1. **Clone the repository**:

    ```bash
    git clone https://github.com/YoussefAhmed100/online-shoping-systems
    ```

2. **Navigate to the project directory**:

    ```bash
    cd online-shoping-systems
    ```

3. **Install the dependencies**:

    Using `npm`:

    ```bash
    npm install
    ```

---

### Usage

Run the project with:

Using `npm`:

```bash
npm start
